# Project Details

## Title
AI-Based RF Signal Monitoring & Anomaly Detection System

## Domain
ECE, signal processing, artificial intelligence, machine learning and web development.

## Objective
Analyze RF signal features and flag unusual patterns using machine learning.

## Modules
1. Signal simulation
2. Feature generation
3. ML anomaly detection
4. Flask API
5. Dashboard visualization
6. Event reporting

## Expected outcome
A working educational prototype demonstrating AI-assisted wireless signal-pattern monitoring.
